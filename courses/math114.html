MATH 114: Quantitative Reasoning

Enhancing data interpretation, logical reasoning, and real-world problem solving.

Course Overview

This course applies mathematical tools and analysis to practical contexts. Emphasis is placed on using proportions, ratios, and basic statistics to solve real-world problems, with a focus on financial applications and data interpretation.

Use this course home as the central starting point for expectations, key logistics, featured course content, and the unit pages that organize assignments, lecture slides, videos, review items, and practice tools.
