What is a function? 9A

  • A function assigns each input exactly one output.
  • Independent variable = input (the cause). Dependent variable = output (the effect).
  • Write it as (input, output), or y = f(x), read "y is a function of x."
  • Ask: "What depends on what?" The thing that depends is the output.

Example: A heating bill depends on outside temperature. Input: temperature. Output: bill.

Four ways to show a function 9A

visits v0123
cost C30354045
  • Words: $30 fee plus $5 per visit.
  • Table: above. Graph: points rise in a straight line.
  • Equation: C = 5v + 30.

On a graph, the input goes on the horizontal axis and the output on the vertical axis.

Domain and range 9A

  • Domain: the input values that make sense.
  • Range: the output values that result.
  • In context, ask what the real situation allows: no negative visits, no negative distance, no time before the start.

Example: d = 100 − 60t. The car arrives when d = 0, at t ≈ 1.67 h. Domain: 0 ≤ t ≤ 1.67. Range: 0 ≤ d ≤ 100.

Describe the relationship 9A

  • Say how the output changes as the input increases: "As altitude increases, air pressure decreases."
  • Sketch a qualitative graph: label axes, show rising, falling, or level, with no exact numbers.
The big idea

Linear Modeling

A model describes a real situation with math. A model is linear when the output changes by the same amount for each unit of input.

output = initial value + (rate of change) × input
y = mx + b

Rate of change and slope 9B

slope m = (y₂ − y₁) ÷ (x₂ − x₁)
= change in output ÷ change in input
  • Units: output units per input unit (dollars per visit, miles per hour).
  • m > 0 rises, m < 0 falls, m = 0 is flat. Larger |m| means steeper.

The linear equation 9B

y = mx + b
  • m = rate of change (slope), with units.
  • b = initial value: the output when x = 0 (the y-intercept).
  • Same m, different b: parallel lines.
  • Linear test for a table: equal input steps give equal output changes. If the change is not constant, the model is not linear.

Build a model

From words: the starting amount is b, the "per" amount is m. Decreasing means a negative m.

Example: 100 miles away, approaching at 60 mph: d = 100 − 60t.

From two points ($50 in year 2, $80 in year 5):

  1. Slope: m = (80 − 50) ÷ (5 − 2) = 10 dollars per year.
  2. Substitute a point: 50 = 10(2) + b, so b = 30.
  3. Write it: P = 10t + 30. Check: 10(5) + 30 = 80. ✓

Use the model

  • Predict the output: substitute the input. 8 visits: C = 5(8) + 30 = $70.
  • Find the input: set the model equal to the output and solve. When is the car 10 miles away? 10 = 100 − 60t, so 60t = 90 and t = 1.5 h.
  • Interpret in a sentence with units: "The price rises $10 per year."
  • Check that the answer is inside the domain and makes sense.
  • Graph it in Desmos: type y = 5x + 30.

Common mistakes

  • Dividing change in input by change in output (flip it: output on top).
  • Losing the minus sign when the quantity decreases.
  • Using the first output as b. b is the output at x = 0.
  • Swapping the independent and dependent variables.
  • Leaving off units, or writing them backward (visits per dollar).
  • Using a model outside its domain (a negative distance).

  • find a slope with units from two points or a table
  • write y = mx + b from words or from two points
