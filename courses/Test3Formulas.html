Growth Models

Linear Growth

  • New Value = Initial Value + (Growth Rate × Time)

Exponential Growth

  • Formula (rate 'r'): New Value = Init × (1 + r)t
  • Growth Factor (doubling): 2n
  • Approx. Doubling (Tdbl): Tdbl ≈ 70 / P
  • Exact Doubling (Tdbl): Tdbl = log(2)/log(1+r)
  • Formula (doubling): New Value = Init × 2(t/Tdbl)

Exponential Decay (Half-Life)

  • Formula (Thalf): New Value = Init × (0.5)(t/Thalf)

Descriptive Statistics

Mean (μ or x̄)

  • Sum of values / Count of values

Range

  • Highest Value - Lowest Value

Range Rule of Thumb

  • Std Dev ≈ Range / 4

Distributions

Standard Score (z-score)

  • z = (x - μ) / σ

Relevant Excel Formulas

Note: Replace range with cells (e.g., A1:A10).

Basic Calculations

  • Power: =POWER(n, p) or =n^p
  • Log (Base 10): =LOG10(n)
  • Log (Natural): =LN(n)

Descriptive Statistics

  • Mean: =AVERAGE(range)
  • Median: =MEDIAN(range)
  • Mode (Single): =MODE.SNGL(range)
  • Mode (Multi): =MODE.MULT(range)
  • Min: =MIN(range)
  • Max: =MAX(range)
  • Range: =MAX(range)-MIN(range)
  • Std Dev (Sample): =STDEV.S(range)
  • Std Dev (Pop.): =STDEV.P(range)
  • Quartiles: =QUARTILE.INC(range, q)

Normal Distribution

  • Z-Score: =STANDARDIZE(x, μ, σ)
  • Area left of Z: =NORM.S.DIST(z, TRUE)
  • Z from Area: =NORM.S.INV(area)

Growth/Trend

  • Linear Forecast: =FORECAST.LINEAR(x, y's, x's)
  • Exponential Forecast: =GROWTH(y's, x's, new_x's)
