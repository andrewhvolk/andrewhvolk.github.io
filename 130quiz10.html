The 3-step process for any right-triangle ratio problem

1
Label
Mark θ. Name the sides relative to θ: opp, adj, hyp. If a ratio is given, read two sides from it.
2
Find the third side
Use opp² + adj² = hyp². The hypotenuse is always the longest side.
3
Write the ratios
SOH-CAH-TOA, then flip for csc, sec, cot. Simplify, and rationalize any square root in a denominator.

📖 Worked Example: Coterminal Angles (click to expand)

▼
Problem: Find a positive and a negative angle coterminal with (a) 130° and (b) −5π/6.
Idea
Coterminal angles share the same terminal side. Add or subtract full turns: 360° in degrees, 2π in radians.
(a)
Positive: 130° + 360° = 490°
Negative: 130° − 360° = −230°
(b)
Write 2π with the same denominator: 2π = 12π/6.
Positive: −5π/6 + 12π/6 = 7π/6
Negative: −5π/6 − 12π/6 = −17π/6
Check
If one full turn does not change the sign (for example 800°), keep subtracting turns: 800° − 2(360°) = 80° and 800° − 3(360°) = −280°.

SOH-CAH-TOA and the reciprocals

sin θ = opp/hyp    csc θ = hyp/opp
cos θ = adj/hyp    sec θ = hyp/adj
tan θ = opp/adj    cot θ = adj/opp

Each function in the right column is the reciprocal of the one beside it.

Rationalizing a denominator

Multiply the top and bottom by the root:
3/√5 = 3√5/5
7/(2√10) = 7√10/20
Simplify roots first: √40 = 2√10

📐 Worked Example: One Ratio from Another

▼
Problem: θ is acute and cos θ = 3/7. Find the exact value of csc θ.
Step 1
Label: cos θ = adj/hyp, so adj = 3 and hyp = 7.
Step 2
Third side: opp = √(7² − 3²) = √(49 − 9) = √40 = 2√10.
Step 3
Ratio: csc θ = hyp/opp = 7/(2√10). Rationalize: 7/(2√10) · √10/√10 = 7√10/20.
Note
When the given ratio already contains a root, such as sin θ = √5/3, use it as a side length: opp = √5, hyp = 3, so adj = √(9 − 5) = 2.

How to type answers: fractions like -113 or 3/5; roots as sqrt(29) or √29, for example 2sqrt(29)/29; π as pi, for example -31pi/12.

Section A: Coterminal Angles (5.1)
1
Find a positive and a negative angle coterminal with 247°.
Add 360° for a positive angle. Subtract 360° for a negative one.
2
Find a positive and a negative angle coterminal with −38°.
The given angle is already negative, so the negative answer must be a different angle: subtract another full turn.
3
Find a positive and a negative angle coterminal with −7π/12.
Write one full turn with denominator 12: 2π = 24π/12.
4
Find a positive and a negative angle coterminal with 13π/4.
One full turn is 8π/4. Subtracting one turn leaves a positive angle; subtract a second turn to get a negative one.

Section C: One Ratio from Another (5.2)
8
θ is acute and sin θ = 12/37. Find the exact value of cos θ.
opp = 12, hyp = 37. Find adj = √(37² − 12²).
9
θ is acute and cos θ = √11/6. Find the exact value of csc θ.
adj = √11, hyp = 6. Then opp = √(36 − 11). Remember that (√11)² = 11.
10
θ is acute and sin θ = √7/4. Find the exact value of cot θ. Rationalize the denominator.
opp = √7, hyp = 4, so adj = √(16 − 7) = 3. cot θ = adj/opp.
11
θ is acute and sec θ = 7/3. Find the exact values of tan θ and sin θ.
sec θ = hyp/adj, so hyp = 7 and adj = 3. Then opp = √(49 − 9) = √40; simplify the root.
