# Tech Stack for Degree Quest

## Game Development Options

### Option 1: Web Game (HTML, JavaScript)

*   **Description:** Develop the game as a web application using HTML, JavaScript, and potentially other free libraries like Phaser or PixiJS.
*   **Pros:**
    *   **Accessibility:** Can be played in any web browser without installation.
    *   **Cost-Effective:** Uses free and open-source technologies.
    *   **Easy Distribution:** Can be easily shared and distributed online.
    *   **Cross-Platform:** Works on any device with a web browser.
*   **Cons:**
    *   **Performance Limitations:** May have performance limitations compared to native games.
    *   **Limited Features:** May not have access to all the features of a dedicated game engine.
    *   **Security Concerns:** Web games can be more vulnerable to security exploits.
    *   **Dependency on Browser Compatibility:** Relies on consistent browser behavior across different platforms.

    *   **Tech Stack:**
        *   **Game Engine/Library:** Phaser, PixiJS, or raw JavaScript with Canvas API
        *   **Programming Language:** JavaScript
        *   **Art Software:** Aseprite, GIMP, or any image editing software
        *   **Sound Design Software:** Audacity or any audio editing software
        *   **Version Control:** Git, GitHub

### Option 2: Godot Engine

*   **Description:** Develop the game using the Godot Engine, a free and open-source game engine.
*   **Pros:**
    *   **Dedicated Game Engine:** Provides a wide range of features specifically designed for game development.
    *   **Cross-Platform Support:** Can be deployed to multiple platforms, including desktop, mobile, and web.
    *   **Free and Open-Source:** No licensing fees or royalties.
    *   **Active Community:** Large and active community providing support and resources.
*   **Cons:**
    *   **Learning Curve:** Requires learning the Godot Engine and its scripting language (GDScript).
    *   **Smaller Ecosystem:** Smaller asset store and community compared to Unity.
    *   **Less Mature:** May have fewer features and less stability compared to more established engines.

    *   **Tech Stack:**
        *   **Game Engine:** Godot Engine
        *   **Programming Language:** GDScript
        *   **Art Software:** Aseprite, GIMP, or any image editing software
        *   **Sound Design Software:** Audacity or any audio editing software
        *   **Version Control:** Git, GitHub

## Art Software

*   **Aseprite:** A pixel art editor for creating sprites and animations.
    *   **Reason:** Aseprite is specifically designed for pixel art and offers a wide range of features for creating high-quality sprites.
*   **Alternative: Adobe Photoshop:** A professional image editing software that can be used for creating and editing game art.
    *   **Reason:** Photoshop is a powerful tool with a wide range of features, but it can be expensive.

## Sound Design Software

*   **Audacity:** A free and open-source audio editor for creating and editing sound effects and music.
    *   **Reason:** Audacity is a versatile tool that can be used for a wide range of audio tasks.
*   **Alternative: FL Studio:** A professional music production software that can be used for creating original music for the game.
    *   **Reason:** FL Studio is a powerful tool with a wide range of features, but it can be expensive.

## Version Control

*   **Git:** A distributed version control system for tracking changes to the codebase.
    *   **Reason:** Git is essential for collaboration and allows developers to easily revert to previous versions of the code.
*   **GitHub:** A web-based platform for hosting Git repositories.
    *   **Reason:** GitHub provides a convenient way to collaborate on code and track issues.

## Level Design Tools

*   **Tiled:** A free and open-source tile map editor for creating game levels.
    *   **Reason:** Tiled is a versatile tool that can be used to create a wide range of levels.
