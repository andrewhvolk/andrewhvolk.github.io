Apply the factor toolbox

Restrictions survive cancellation

  1. 1Factor numerator.
  2. 2Factor denominator.
  3. 3Write original restrictions.
  4. 4Cancel common factors.
(x2 − 9)/(x2 + 6x + 9)
(x+3)(x−3) / [(x+3)(x+3)]

= (x−3)/(x+3),   x ≠ −3
Cancel factors, never termsR = reveal
