## Entrance Check

### Entrance 1 — Exponent quotient

- **Type:** Multiple choice, one correct answer
- **Suggested time:** 45 seconds
- **Prompt:** Simplify with positive exponents only: `x^5 / x^8`
- **A:** `x^3`
- **B:** `1/x^3` **(correct)**
- **C:** `x^13`
- **D:** `1/x^13`
- **Feedback:** Subtract exponents: `5 − 8 = −3`; then `x^−3 = 1/x^3`.
- **Routing rule:** If fewer than 70% answer correctly, use deck Appendix A before the factor-first lesson.

### Entrance 2 — Interval notation

- **Type:** Multiple choice, one correct answer
- **Suggested time:** 60 seconds
- **Prompt:** Write `{x | −2 < x ≤ 4}` in interval notation.
- **A:** `[−2,4]`
- **B:** `(−2,4]` **(correct)**
- **C:** `[−2,4)`
- **D:** `(−2,4)`
- **Feedback:** `−2` is excluded, so use `(`. The endpoint `4` is included, so use `]`.
- **Routing rule:** If fewer than 70% answer correctly, use deck Appendix B before the factor-first lesson.

### Entrance 3 — Factor completely

- **Type:** Multiple choice, one correct answer
- **Suggested time:** 90 seconds
- **Prompt:** Factor completely: `6x^3 − 9x^2`
- **A:** `3x^2(2x − 3)` **(correct)**
- **B:** `3x(2x^2 − 3x)`
- **C:** `x^2(6x − 9)`
- **D:** `3x^2(2x + 3)`
- **Feedback:** The full GCF is `3x^2`. Choices B and C are equivalent expressions but are not completely factored; D has a sign error.
- **Routing rule:** Below 50% correct, remain on GCF/difference-of-squares/simple trinomials and skip the LCD extension. At 70% or higher, move quickly into restrictions and preserve the LCD extension.

## Exit Check

### Exit 1 — Simplify and preserve restrictions

- **Type:** Multiple choice, one correct answer
- **Suggested time:** 90 seconds
- **Prompt:** Simplify `(x^2 − 4)/(x^2 + x − 6)` and state all restrictions from the original expression.
- **A:** `(x+2)/(x+3)`, `x ≠ −3`
- **B:** `(x+2)/(x+3)`, `x ≠ 2, −3` **(correct)**
- **C:** `(x−2)/(x−3)`, `x ≠ 2, 3`
- **D:** `1`, `x ≠ 2, −3`
- **Feedback:** Factor to `(x−2)(x+2)/[(x−2)(x+3)]`. Cancel the common factor, but retain both original restrictions: `x ≠ 2, −3`.
- **Interpretation:**
  - 75% or higher: class is ready for LCDs and unlike-denominator addition.
  - 50–74%: repeat one factor/restriction bridge before advancing.
  - Below 50%: plan a factoring intervention before rational-expression operations.

### Exit 2 — Next-step blocker

- **Type:** Poll or multiple choice; no correct answer
- **Suggested time:** 30 seconds
- **Prompt:** Where is your first point of hesitation right now?
- **A:** Choosing a factoring method
- **B:** Factoring completely
- **C:** Finding restrictions
- **D:** Canceling only complete factors
- **E:** I am ready for LCDs and unlike denominators
- **Use:** Group the next warm-up or ALEKS support by the most common response. If Top Hat limits the activity to four choices, omit E and identify extension readiness from Exit 1.

## Optional extension question

Use only if Entrance 3 is at least 70% correct and the class reaches the LCD extension.

- **Type:** Multiple choice, one correct answer
- **Suggested time:** 75 seconds
- **Prompt:** Find the LCD for `1/(x^2 − 4) + 1/(x^2 + x − 6)`.
- **A:** `(x−2)`
- **B:** `(x−2)(x+2)(x+3)` **(correct)**
- **C:** `(x−2)^2(x+2)(x+3)`
- **D:** `(x+2)(x+3)`
- **Feedback:** The factored denominators share `(x−2)`, so the LCD needs only one copy of that factor.
