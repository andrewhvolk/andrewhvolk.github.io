01Sets — Intervals, Union, Intersection▼

Key Concepts

  • Set-builder notation: e.g. \{x \mid x \geq 3\}
  • Interval notation: brackets [ ] include; parentheses ( ) exclude
  • Union A \cup B: elements in either set
  • Intersection A \cap B: elements in both sets

Common Intervals

[a, b] \quad (a, b) \quad [a, \infty) \quad (-\infty, b]
⚡ ∞ and −∞ always get parentheses, never brackets!
02Absolute Value▼

Key Concepts

  • |a| = distance from a to 0 — always ≥ 0
  • |a| = a if a \geq 0; |a| = -a if a < 0
|x| = c \implies x = c \text{ or } x = -c \quad(c \geq 0)
⚡ Remember: \sqrt{x^2} = |x|
03Exponents▼

Core Laws

  • a^m \cdot a^n = a^{m+n}
  • \frac{a^m}{a^n} = a^{m-n}
  • (a^m)^n = a^{mn}
  • (ab)^n = a^n b^n
  • a^{-n} = \frac{1}{a^n}
⚡ Write all final answers with positive exponents only.
04Factoring▼

Methods (always start with GCF!)

  • GCF — always factor out first
  • Grouping — split into pairs
  • Difference of squares: a^2 - b^2 = (a-b)(a+b)
  • Difference of cubes: a^3 - b^3 = (a-b)(a^2+ab+b^2)
  • Sum of cubes: a^3 + b^3 = (a+b)(a^2-ab+b^2)
  • Trinomials: find two numbers that multiply to ac and add to b
⚡ Mnemonic for cubes: "SOAP" — Same, Opposite, Always Positive.
05Operations with Fractions & Rational Expressions▼
  • Always factor first
  • Add/subtract: find LCD, rewrite, combine numerators
  • Multiply: factor → cancel → multiply
  • Divide: flip second fraction → multiply
⚡ Factor first! This is the #1 mistake on rational expression problems.
06Equations — Linear & Quadratic▼

Linear

  • Distribute, combine like terms, isolate variable
  • With fractions: multiply by LCD
  • Watch for no solution or all reals

Quadratic

  • Factor or use quadratic formula
  • Rational equations: check for extraneous solutions!
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
07Midpoint & Distance Formula▼
\text{Midpoint} = \left(\frac{x_1+x_2}{2},\frac{y_1+y_2}{2}\right)
d = \sqrt{(x_2-x_1)^2+(y_2-y_1)^2}
⚡ Round to one decimal place when instructed!
08Equation of a Circle▼
(x-h)^2 + (y-k)^2 = r^2

Center = (h,k), Radius = r

⚡ Right side is r², not r. Radius 5 → write 25.
09Lines — Slope, Forms, Parallel & Perpendicular▼
  • Slope-intercept: y = mx + b
  • Point-slope: y - y_1 = m(x - x_1)
  • General: Ax + By + C = 0
\text{Parallel: } m_1 = m_2 \qquad \text{Perp: } m_1 \cdot m_2 = -1
⚡ Perpendicular: flip and negate. Slope 3 → perp slope −1/3.
10Maximum/Minimum of a Quadratic — Vertex▼
x = -\frac{b}{2a}

Plug back into f(x) for the max/min value.

  • a > 0 → minimum
  • a < 0 → maximum
⚡ The question usually wants the y-value (height, etc.), not the x-value.
